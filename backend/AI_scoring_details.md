# AI Resume Review System – Full Scoring & Feedback Specification

## 1. System Overview

This system analyzes a user's resume against a target job role (and optional job description) using an AI API.

### High-level flow

```txt
Upload Resume (PDF/DOCX)
→ Extract text
→ Apply length limits
→ Build AI prompt
→ Send to AI API
→ Receive structured JSON
→ Save to database
→ Display feedback + history
```

---

## 2. Input Data

### From Frontend

```json
{
  "resume": "File (PDF/DOCX)",
  "target_job_role": "Frontend Developer",
  "target_job_description": "Optional job description text"
}
```

---

## 3. Preprocessing Rules (Backend)

### Resume

* Extracted into plain text
* Max length: **5000 characters**

If exceeded:

```json
{
  "resume_text_truncated": true
}
```

---

### Job Description

* Optional
* Max length: **2500 characters**

If exceeded:

```json
{
  "job_description_truncated": true
}
```

---

### Job Description Quality

If length < 80 chars:

```json
{
  "missing_job_information": true
}
```

---

## 4. AI Prompt Design

The backend sends a structured instruction to the AI.

### Core Instruction

```txt
You are an AI resume reviewer.

Analyze the resume against the target job role and optional job description.
```

---

### Key Rules Passed to AI

```txt
1. Target job role is required.
2. Job description is optional.
3. If JD exists → use it.
4. If JD missing/short → use industry standards.
5. If resume truncated → mention it.
6. If JD truncated → mention it.
7. Identify missing resume sections.
8. Missing sections must affect scoring.
9. Be concise.
10. Return ONLY JSON.
```

---

### Output Constraints

```txt
- Max 5 items per list
- Each item = 1 short sentence
- Summary < 60 words
- No markdown
- No extra explanation outside JSON
```

---

## 5. Scoring Rubric (Total = 100)

| Category             | Weight |
| -------------------- | ------ |
| Skills Match         | 30     |
| Experience Relevance | 25     |
| Education            | 15     |
| Projects / Evidence  | 15     |
| ATS Readability      | 15     |

---

## 6. Scoring Logic

* Score is generated by AI using rubric
* Backend does NOT calculate score manually
* AI evaluates based on:

  * Resume content
  * Job role
  * Job description (if available)
  * Missing data
  * Truncation

---

## 7. AI Output Format

AI MUST return JSON in this structure:

```json
{
  "score": 82,
  "summary": "Strong frontend skills with solid project experience.",
  "confidence": "medium",
  "evaluation_basis": "Based on general industry standards due to missing job description.",
  "missing_resume_sections": ["certifications"],
  "missing_job_information": true,

  "resume_text_truncated": false,
  "resume_length_warning": "",

  "job_description_truncated": false,
  "job_description_warning": "",

  "impact_explanation": "Score reduced due to lack of professional experience.",

  "strengths": [
    "Strong React and Next.js skills.",
    "Relevant frontend projects.",
    "Good understanding of responsive design."
  ],

  "areas_for_improvement": [
    "Limited professional work experience.",
    "Missing testing framework experience."
  ],

  "actionable_suggestions": [
    "Add 2–3 real-world projects.",
    "Include testing tools such as Jest."
  ],

  "matched_skills": [
    "React",
    "JavaScript",
    "HTML",
    "CSS"
  ],

  "missing_skills": [
    "Testing",
    "Accessibility"
  ],

  "extra_skills": [
    "Python",
    "AWS"
  ],

  "resume_data": {
    "work_experience": ["Intern at XYZ"],
    "skills": ["React", "JavaScript"],
    "education": ["Bachelor of IT"],
    "projects": ["Portfolio Website"],
    "certifications": [],
    "missing_sections": ["certifications"]
  }
}
```

## 8. Feedback Structure

### Strengths

* What the user did well

### Areas for Improvement

* Weak points in resume

### Actionable Suggestions

* Specific steps to improve

---

## 9. ATS Skill Matching

Three categories:

```txt
matched_skills → required + present
missing_skills → required + absent
extra_skills → not required but useful
```

---

## 10. Confidence Levels

| Level  | Meaning                  |
| ------ | ------------------------ |
| High   | Full data available      |
| Medium | Some missing info        |
| Low    | Significant missing data |

---

## 11. Evaluation Basis

Explains scoring source:

```txt
- Based on job description
- OR based on industry standards
```

---

## 12. Impact Explanation

Explains score deductions:

```txt
- Missing experience
- Weak skills match
- Missing JD
- Truncated resume
```

---

## 13. Missing Resume Sections

AI checks:

```txt
- Work experience
- Skills
- Education
- Projects
- Certifications
```
